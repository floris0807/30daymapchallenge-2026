# 30DayMapChallenge 2026

Daily maps for [#30DayMapChallenge](https://30daymapchallenge.com/) 2026, focused on the sea and the weather around Japan.
海と気象を題材に、毎日1枚の地図を作っています。

Live: https://floris0807.github.io/30daymapchallenge-2026/

| Day | Theme | Map | Data |
|---|---|---|---|
| 13 | Interactions | [風と波 — 日本近海](https://floris0807.github.io/30daymapchallenge-2026/day13-interactions/) | Open-Meteo Marine / Forecast API |

## Stack
- [MapLibre GL JS](https://maplibre.org/) + [OpenFreeMap](https://openfreemap.org/)
- Each day is a single static folder: `index.html`, a data snapshot, and the script that fetched it
